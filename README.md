# 🛍️ React E-commerce UI

A modern and responsive E-commerce UI built with React and Tailwind CSS.

---

## 🚀 Features

- Responsive Design
- Hero Section
- Product Cards
- Product Categories
- Testimonials
- Smooth Animations
- Mobile Friendly

---

## 🛠️ Tech Stack

- React
- Tailwind CSS
- JavaScript
- Vite

---

## 📚 What I Learned

- React Components
- Props
- State Management
- Component Reusability
- Responsive Design
- Tailwind CSS
- React Icons

---

## ⚙️ Installation

```bash
git clone https://github.com/Habibullah-Bahar/react-ecommerce-ui.git

cd react-ecommerce-ui

npm install

npm run dev
```
